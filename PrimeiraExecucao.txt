PASSO A PASSO — PRIMEIRA EXECUÇÃO
PASSO 1 — Autenticar Claude Code CLI (só 1x na vida)
Duplo clique em:

CONECTAR-CLAUDE.bat
Uma janela abre. O script vai:

Confirmar que o CLI está instalado (v2.1.150 ✅)
Testar autenticação → detectar que ainda não está logado
Mostrar as instruções e perguntar se quer prosseguir
Quando aparecer a pergunta: pressione Enter

O Claude Code interativo abre na mesma janela. Você vai ver algo como:

Welcome to Claude Code!
>
Digite exatamente:

/login
Pressione Enter.

O navegador abre automaticamente → entre com a sua conta Claude Pro → autorize.

Volte ao terminal → pressione Enter ou Ctrl+C → depois /exit para sair.

O script verifica automaticamente e mostra:

[OK] LOGIN REALIZADO COM SUCESSO!
[OK] Motor ativo: Claude Code CLI (plano Pro)

Resumo dos arquivos (duplo clique)
Arquivo	Para que serve
CONECTAR-CLAUDE.bat	PRIMEIRO — autenticar o CLI com Claude Pro (1x)
INICIAR-INTEGRACAO.bat	Iniciar o pipeline completo
PARAR-INTEGRACAO.bat	Parar tudo com segurança
Fluxo completo após autenticação:

S10 envia áudio
    → KDE Connect recebe no Downloads
    → watcher.py detecta → Whisper transcreve (~7s)
    → gera transcricao.md no inbox_tarefas/
    → inbox_watcher.py detecta
    → processar_com_claude_code.py dispara
    → claude -p envia para Claude Pro
    → Claude classifica P1/P2/P3 + executa PowerShell seguros
    → salva tarefas_priorizadas.md + execucao.md
