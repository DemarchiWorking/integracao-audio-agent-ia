PARTE 2 — CONFIGURAR UMA VEZ (pre-requisitos)
==============================================================

PASSO A — Configurar chave da API Anthropic
--------------------------------------------
1. Acesse: https://console.anthropic.com/
2. Va em "API Keys" -> "Create Key"
3. Copie a chave (comeca com "sk-ant-...")
4. No Windows, abra PowerShell e execute:
   [Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY","sk-ant-SUA-CHAVE-AQUI","User")
5. Feche e reabra o PowerShell para aplicar

PASSO B — Instalar SDK Anthropic para Python
---------------------------------------------
   pip install anthropic

PASSO C — Instalar KDE Connect no S10 FE
-----------------------------------------
1. No S10 FE, abra a Play Store
2. Busque: "KDE Connect"
3. Instale o app (desenvolvedor: KDE)
4. Abra o app e conceda todas as permissoes

PASSO D — Parear S10 FE com o Windows
----------------------------------------
1. Coloque o S10 FE e o PC na MESMA rede WiFi
   (o PC esta em: 192.168.3.65)
2. No Windows: Menu Iniciar -> buscar "KDE Connect" -> abrir
3. No S10 FE: app KDE Connect -> vai mostrar "DESKTOP-N3BPMC5"
4. Toque no nome do PC -> "Solicitar pareamento"
5. No Windows: aceite a solicitacao de pareamento
6. Teste: no S10 FE, toque nos 3 pontinhos -> "Enviar arquivo"
   -> envie qualquer foto -> ela deve aparecer em Documents\KDE Connect\

PASSO E — Configurar pasta de recebimento do KDE Connect
----------------------------------------------------------
No Windows, abra KDE Connect -> clique no S10 FE -> Configuracoes
-> "Compartilhamento de Arquivos" -> "Pasta de Download"
-> Troque para: C:\Users\Antonio Demarchi\Documents\KDE Connect\
(provavelmente ja esta correto)

==============================================================
PARTE 6 — TROUBLESHOOTING
==============================================================

PROBLEMA: KDE Connect nao encontra o S10 FE
SOLUCAO:  Verificar se ambos estao na mesma rede WiFi (192.168.3.x)
          No Windows: Firewall -> permitir KDE Connect
          winget install KDE.KDEConnect (se precisar reinstalar)

PROBLEMA: Audio chega mas nao e processado
SOLUCAO:  Verificar extensao (.m4a, .wav, .mp3 sao suportados)
          Verificar log: Get-Content orchestrator\api_err.log

PROBLEMA: Transcricao muito imprecisa
SOLUCAO:  Falar mais devagar e perto do microfone
          Modelo base e bom para PT-BR real. TTS de teste e menos preciso.
          Para mais precisao, mudar para modelo "small":
          $env:WHISPER_MODEL = "small" (antes de iniciar)

PROBLEMA: "Orquestrador offline" no watcher
SOLUCAO:  O watcher sobe antes da API. Aguardar 5s ou rodar start.ps1 de novo.

PROBLEMA: processar_agora.ps1 nao encontra 'claude'
SOLUCAO:  Usar processar_com_claude.py (via API Anthropic)
          Configurar ANTHROPIC_API_KEY (ver Parte 2, Passo A)
